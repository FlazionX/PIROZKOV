# DANCE.EXE

## Скачать готовую версию

[Скачать DANCE.EXE для Windows (GitHub Releases)](https://github.com/FlazionX/PIROZKOV/releases/latest/download/DANCE.EXE-Windows.zip)

SHA-256 файл находится рядом с архивом релиза. Если браузер всё ещё считает файл опасным, не отключай защиту: это означает, что Google ещё не проверил файл либо пометил его как подозрительный.

Музыкальный визуальный розыгрыш для Windows 10/11: стандартное окно Windows, музыка, фотографии, GIF-анимации, плавные световые эффекты и цветная подсветка панели задач.

## Музыка

Программа автоматически ищет аудио в следующих местах:

- \`assets/samo_soboy.mp3\` — основной вариант;
- \`samo_soboy.mp3\` рядом с \`PIROZKOV.exe\`;
- другие MP3/WAV/M4A/AAC в \`assets\`, рядом с EXE или в папках \`music\`.

Если файл не найден, при нажатии «Да» откроется обычное окно Windows, в котором можно выбрать аудиофайл вручную. Поэтому имя файла больше не обязательно должно быть идеальным.

Рекомендуемое имя: \`samo_soboy.mp3\`.

## Фотографии и GIF

Фотографии добавляй в \`assets/photos/\`. Поддерживаются JPG, JPEG, PNG, WEBP и BMP. Они уменьшаются и подготавливаются в отдельном потоке.

Необязательные GIF добавляй в \`assets/gifs/\`. Лучше короткие GIF размером около 200–400 пикселей. На экране показывается не более двух одновременно.

## Текст DANCE SYSTEM

Добавь собственный файл \`assets/captions.srt\` в формате SubRip:

\`\`\`srt
1
00:00:05,000 --> 00:00:08,000
Твоя строка текста

2
00:00:08,500 --> 00:00:11,000
Следующая строка
\`\`\`

Полный текст песни в проект не включён — добавляй текст, на использование которого у тебя есть права.

## Запуск и сборка

- Запускай \`PIROZKOV.exe\` из распакованной папки.
- Не отделяй EXE от папки \`_internal\`.
- Папку \`assets\` держи рядом с EXE.
- Для сборки из исходников используй \`build.bat\`.

GitHub Actions публикует архив \`PIROZKOV-Windows\` в разделе Actions. Внутри архива EXE, \`_internal\` и папка \`assets\`.

## Эффекты

1. Обычное компактное окно Windows 10: «Хочешь Танцевать?».
2. Центральное фото плавно увеличивается и исчезает.
3. Музыка, радужный свет, диско-шар и мягкие лучи.
4. Плавные фотографии и дополнительные GIF с краёв экрана.
5. Радужная подсветка поверх нижней панели задач, клики проходят к Windows.
6. Настоящие значки рабочего стола пытаются перемещаться через Windows Shell COM API и восстанавливаются при штатном выходе.

Для выхода нажми **Ctrl + Shift + F10**.

## Диагностика

При ошибке воспроизведения программа показывает сообщение, а подробности сохраняет в \`PIROZKOV-error.txt\` рядом с EXE. Если музыка не находится автоматически, выбери файл в открывшемся диалоге.
