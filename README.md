# PIROZKOV.exe

Безопасный полноэкранный музыкальный розыгрыш для Windows. Программа не удаляет и не изменяет пользовательские файлы, не меняет системные настройки и не трогает настоящие ярлыки рабочего стола: прыгающие значки — визуальная имитация внутри окна приложения.

## Запуск из исходников

1. Установи Python 3.10+.
2. Положи легально полученный аудиофайл трека «Само собой» в `assets/samo_soboy.mp3`.
3. (Необязательно) Добавь собственные субтитры в `assets/captions.srt` (формат SRT). Каждая строка появляется в отдельном небольшом окне по таймкодам.
4. Запусти `run.bat`.

## Получение EXE

GitHub Actions автоматически собирает Windows-версию при изменениях кода. Открой вкладку **Actions**, выбери успешный запуск **Build Windows EXE** и скачай артефакт **PIROZKOV-Windows**. В архиве будет `PIROZKOV.exe` и папка `assets`.

Можно собрать локально командой `build.bat`. Готовый файл появится в `dist/PIROZKOV.exe`. Сборка настроена без `--collect-all PySide6`: это исключает упаковку всех необязательных модулей Qt, которые программа не использует, и должно заметно уменьшить размер. Точный размер зависит от версии Python, PySide6 и PyInstaller.

Перед запуском положи свою копию трека в `assets/samo_soboy.mp3`. Музыка и полный текст песни не включены в репозиторий. Субтитры пользователь добавляет самостоятельно.

## Что происходит

- Полупрозрачная радужная анимация отображается поверх рабочего стола Windows.
- Настоящие значки рабочего стола остаются на месте и доступны для нажатия.
- Фотографии появляются в случайных местах экрана. Программа пытается загрузить их при первом запуске; можно также положить собственные JPG/PNG в `assets/photos`.
- Строки из собственного SRT-файла появляются в отдельных плавающих окнах.
- После окончания трека приложение закрывается автоматически.

## Управление

- **Ctrl + Shift + F10** — аварийный выход из сцены.

## Важно

Это визуальный розыгрыш с явным выходом. Сцена работает как прозрачный слой над рабочим столом; обычного окна приложения нет. Она не закрывает чужие приложения, не перемещает настоящие значки, не запускается автоматически вместе с Windows и пропускает нажатия мыши к рабочему столу.
