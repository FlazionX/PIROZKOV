# DANCE.EXE

Музыкальный розыгрыш для Windows с окном-приглашением, диско-эффектами, плавающими фотографиями и текстовыми окнами по таймкодам.

## Подготовка файлов

Перед запуском положи свою копию аудио в:

`assets/samo_soboy.mp3`

Добавь фотографии Артура Пирожкова в:

`assets/photos/`

Поддерживаются JPG, JPEG, PNG, WEBP и BMP. Можно положить 35 или больше фотографий — программа загрузит до 300 файлов и будет выбирать их случайным образом. На экране одновременно отображается до 20 квадратных фотографий.

Чтобы появлялись окна DANCE SYSTEM с текстом, добавь собственный файл:

`assets/captions.srt`

В нём указываются строки и время их появления. Пример формата:

```srt
1
00:00:05,000 --> 00:00:08,000
Твоя строка текста

2
00:00:08,500 --> 00:00:11,000
Следующая строка
```

Текстовые окна синхронизируются с позицией воспроизведения музыки. Полный текст песни в проект не включён — добавляй текст, на использование которого у тебя есть права.

## Сценарий

1. Появляется окно DANCE.EXE с вопросом «Хочешь Танцевать?».
2. Кнопка «НЕТ» убегает от курсора; «ДА» запускает сцену.
3. Фотография появляется в центре, увеличивается и плавно исчезает.
4. Начинается музыка, появляются радужные лучи и цветная подсветка нижней панели.
5. Фотографии плавно прилетают с краёв экрана, покачиваются и перемещаются.
6. В моменты из SRT появляются окна DANCE SYSTEM.
7. На Windows программа также пытается слегка перемещать настоящие значки рабочего стола и возвращает их на исходные места при штатном завершении.

## Запуск и сборка

- Из исходников: запусти `run.bat`.
- Сборка EXE: запусти `build.bat`.
- Готовая программа: `dist/PIROZKOV/PIROZKOV.exe`.

После сборки запускай `dist/PIROZKOV/PIROZKOV.exe`. Не отделяй EXE от папки `_internal`; папка `assets` также должна находиться рядом с EXE. Если добавляешь или меняешь музыку, фотографии или SRT после сборки, положи их в `dist/assets`.

## Выход

Нажми **Ctrl + Shift + F10** для штатного завершения. Программа должна вернуть значки рабочего стола на сохранённые позиции. Не завершай процесс принудительно через диспетчер задач во время анимации значков.
