# DANCE.EXE

Музыкальный визуальный розыгрыш для Windows 10/11: обычное окно Windows, музыка, фотографии, GIF-анимации, световые эффекты на всём экране и цветная подсветка панели задач.

## Подготовка файлов

Положи аудиофайл под именем:

`assets/samo_soboy.mp3`

Добавь фотографии в:

`assets/photos/`

Поддерживаются JPG, JPEG, PNG, WEBP и BMP. Программа загружает изображения в отдельном потоке и уменьшает их до небольших квадратных превью, чтобы не задерживать открытие окна и не декодировать полноразмерные фотографии во время анимации.

Необязательные GIF-анимации добавляй в:

`assets/gifs/`

Лучше короткие GIF размером около 200–400 пикселей. Программа показывает не более двух GIF одновременно и старается привязывать их появление к смене строк песни. Если папка пустая, этот эффект просто отключается.

Для небольших окон DANCE SYSTEM добавь собственный файл:

`assets/captions.srt`

Пример формата:

```srt
1
00:00:05,000 --> 00:00:08,000
Твоя строка текста

2
00:00:08,500 --> 00:00:11,000
Следующая строка
```

Полный текст песни в проект не включён — добавляй текст, на использование которого у тебя есть права.

## Эффекты

1. Открывается стандартное окно DANCE.EXE в стиле Windows 10 с вопросом «Хочешь Танцевать?».
2. Кнопка «Нет» уклоняется от нажатия; «Да» запускает сцену.
3. Центральная фотография плавно увеличивается и исчезает с мягким световым ореолом.
4. Начинается музыка; поверх всего экрана появляются медленно движущаяся радужная подсветка, лучи и диско-шар.
5. Нижняя полоса эффекта проходит по панели задач Windows, не блокируя нажатия.
6. Квадратные фотографии входят с краёв экрана, плавно перемещаются и слегка покачиваются.
7. В музыкальные моменты появляются GIF-анимации, если они добавлены в `assets/gifs/`.
8. Окна DANCE SYSTEM используют обычный системный вид и показывают строки из SRT по таймкодам.

## Настоящие значки рабочего стола

Для перемещения реальных значков используется поддерживаемый COM-интерфейс Windows `IFolderView::SelectAndPositionItems`, а не старые сообщения внутреннему элементу ListView. Нативный helper временно выключает автоупорядочивание значков, запоминает исходные координаты и восстанавливает их и настройку автоупорядочивания при штатном выходе.

GitHub Actions собирает `desktop_icons.cpp` в `desktop_icons.dll` на Windows и включает DLL в готовую программу. Для локальной сборки через `build.bat` нужен компилятор MSVC; без него соберётся визуальная часть, но настоящие значки перемещаться не будут. Если Explorer не предоставляет рабочий COM-интерфейс, анимация значков безопасно отключается.

Как и у любого управления рабочим столом через Explorer, гарантировать движение значков на каждой конфигурации Windows нельзя: режимы организации значков, ограничения оболочки и сторонние программы могут мешать.

## Запуск и сборка

- Из исходников: `run.bat`.
- Локальная сборка: `build.bat`.
- Готовая программа GitHub Actions: скачай архив `PIROZKOV-Windows` из раздела Actions.

Запускай `dist/PIROZKOV/PIROZKOV.exe`. Не отделяй EXE от папки `_internal`; папка `assets` также должна находиться рядом с EXE. Если меняешь материалы после сборки, клади их в `dist/PIROZKOV/assets/`.

Сборка использует режим onedir: рядом с EXE остаётся папка `_internal`. Это сделано намеренно — такой запуск не распаковывает весь пакет заново при каждом старте.

## Выход

Нажми **Ctrl + Shift + F10** для штатного завершения. Программа останавливает анимацию и пытается вернуть исходные позиции значков и исходное состояние автоупорядочивания. Не завершай процесс принудительно через диспетчер задач во время анимации.
