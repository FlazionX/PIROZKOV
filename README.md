# PIROZKOV.exe

Безопасный полноэкранный музыкальный розыгрыш для Windows. Программа не удаляет и не изменяет пользовательские файлы, не меняет системные настройки и не трогает настоящие ярлыки рабочего стола: прыгающие значки — визуальная имитация внутри окна приложения.

## Запуск

1. Установи Python 3.10+.
2. Положи легально полученный аудиофайл трека «Само собой» в `assets/samo_soboy.mp3`.
3. (Необязательно) Добавь собственный файл субтитров `assets/captions.srt` в формате SRT. Приложение покажет строки по таймкодам из файла.
4. Запусти `run.bat` или выполни:
   ```bash
   pip install -r requirements.txt
   python main.py
   ```

## Сборка EXE

Запусти `build.bat`. Готовый файл появится в `dist/PIROZKOV.exe`. Для работы рядом с EXE должна находиться папка `assets` с музыкой и субтитрами (PyInstaller one-file не включает эти пользовательские медиа автоматически).

## Управление

- Кнопка «ПРОПУСТИТЬ» закрывает розыгрыш и останавливает музыку.
- `Esc` или `F10` — аварийный выход.
- После окончания аудиофайла приложение закрывается автоматически.

## Важно

Это розыгрыш с явным выходом. Он не закрывает чужие приложения принудительно, не перемещает настоящие значки, не запускается автоматически вместе с Windows и не блокирует клавиатуру/мышь. На данном этапе иконки и радужный фон рисуются внутри полноэкранного окна.
